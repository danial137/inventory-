# 📦 Inventory Management System

A full-stack inventory management system built to manage products, sales, purchases, and inventory data.

This project is being developed as a practical full-stack application to strengthen my experience with frontend development, backend development, REST APIs, databases, and application architecture.

> 🚧 **Status:** Currently under development

---

## 🧩 Project Structure

The project is divided into two main applications:

### 🖥️ Client

The frontend application responsible for the user interface and interaction with the inventory management system.

**Technologies:**

* React
* TypeScript
* Modern frontend development tools

➡️ [View Client README](./client/README.md)

---

### ⚙️ Server

The backend application responsible for the API, business logic, database communication, and server-side functionality.

**Technologies:**

* Node.js
* Express.js
* TypeScript
* Prisma ORM
* PostgreSQL

➡️ [View Server README](./server/README.md)

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/danial137/inventory-.git
```

Navigate into the project:

```bash
cd inventory-
```

### Client

```bash
cd client
npm install
npm run dev
```

### Server

Open another terminal:

```bash
cd server
npm install
npm run dev
```

> Make sure PostgreSQL is running and the required environment variables are configured before starting the server.

---

## 🔐 Environment Variables

The client and server may require environment variables for local development.

Create the appropriate `.env` files inside the corresponding directories and configure them according to your local environment.

For security reasons, never commit your `.env` files or database credentials to GitHub.
